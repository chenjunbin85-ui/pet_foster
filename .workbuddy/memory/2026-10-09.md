## 技术要点（Base UI 迁移踩坑）
本项目的 `components/ui/*` 是 shadcn 的 **Base UI 版**（依赖 `@base-ui/react`），不是 Radix 版。Radix 允许 `DropdownMenuLabel` 独立使用；Base UI 不允许 —— 所有 `*GroupLabel`（DropdownMenuLabel / SelectLabel 等）必须包在对应 Group 内，否则运行时抛错并可能整页白屏。
其它差异：`Menu.Item` 的禁用属性渲染为 `aria-disabled="true"` + `data-disabled=""`（元素是 `div`，不是原生 button），e2e 断言禁用态要查这两个属性。

**语义（用户选择）**：后端统一限流，按账号计数，5 分钟窗口内失败 5 次锁定 5 分钟，登录成功清零；内存实现，服务重启清空。

## 修复：浮窗（对话框）没有水平垂直居中（用户截图反馈）

**现象**：角色切换浮窗贴着视口顶部、偏左，不在屏幕中央。

**根因（实测数据，非推断）**：确认 Base UI **不给 popup 注入任何定位样式**（它只管焦点/无障碍/Dismiss），
定位完全由业务 CSS 决定。而 `index.css` 里我此前用 `[data-slot="dialog-content"][data-open] { transform: translate(-50%,-50%) scale(1) }`
配合 `ui/dialog.tsx` 里的 `top-1/2 left-1/2 -translate-x-1/2 -translate-y-1/2` 做居中，
但 `dialog.tsx` 的类已被我上一轮清理过，只剩 CSS 那层 translate —— 于是**位移量加在了错误的位置**。
实测（1440×900，浮窗 440×428）：
```
rect = (280, 21.8)   期望居中位置 = (500, 235.9)
offset = { dx: -220, dy: -214.1 }   ← 正好是自身 宽/2 、高/2
```
即：**translate(-50%,-50%) 的位移被应用了，但缺少 `top:50%/left:50%` 这个基准点**，所以往左上角偏了半个身位。

**修复**（三处）：
1. `index.css` 的 `[data-slot="dialog-content"] / [data-slot="alert-dialog-content"]`：
   改为 **`position:fixed; inset:0; margin:auto`** 方案 —— 四边约束到视口 + `margin:auto` 实现双向居中；
   `height:fit-content` 让高度按内容收缩，`max-height:calc(100svh - 48px)` + `overflow-y:auto` 兜住矮窗口。
   入场动画**只叠 `transform: scale(.96)`**，不再写 translate。
2. `ui/dialog.tsx`：`fixed top-1/2 left-1/2 … -translate-x-1/2 -translate-y-1/2 grid` → `fixed inset-0 …`（去掉 translate 与 grid）。
3. `ui/alert-dialog.tsx`：同样处理（`group/alert-dialog-content` 保留，Header/Footer 依赖它的 `group-data-[size=]` 变体）。

**⚠️ 本轮最重要的两个坑（都值得记）**：
1. **`display:grid` + `inset:0` 会把浮窗撑满整屏**：grid 会把 100% 高度**平均分给各行**，
   于是白底容器变成 `440x900`（=整屏高），内容反而被摊开、`max-height` 也失效。
   实测修复前 `gridTemplateRows: "230.75px 359px 228.25px"`（三行瓜分 900px），
   修复后 `flex` + `height:fit-content` → `440x428`，才是正确的内容高度。
   **这个 bug 有很强的迷惑性**：因为内容恰好落在视觉中部，单看截图会以为「已经居中了」。
2. **居中方案要认准一个坐标系**：既然 Base UI 不给 popup 定位，就自己用
   `fixed + inset:0 + margin:auto` 一条路走到底；**不要再混用 `translate(-50%,-50%)`**，
   两者叠加会各自生效、位移翻倍。

**顺带修掉的相关隐患**：`ui/dialog.tsx` / `ui/alert-dialog.tsx` 里残留的 `grid`（与 CSS 的 flex 冲突）一并去掉，
避免「类名写 grid、实际是 flex」的误导。

## 用 Playwright 跑全量 e2e：38 条全绿（含新增天气测试）

**结果**：`38 passed (1.7m)`（原 37 + 天气 1）。

**过程中踩到并解决的两个环境问题（详见 MEMORY.md「坑 4b」）**：

1. **本机全局代理把 localhost 拦成 502** —— `http_proxy`/`https_proxy` 都指向 `127.0.0.1:64306`。
   `curl http://localhost:5173/` 返回 502，但 `curl --noproxy '*' http://127.0.0.1:5173/` 返回 200，
   **差点误判成 dev server 挂了**（实际是代理转发的错误页）。
   首次跑测试 38 条全挂在 `page.goto("/")`，报 `net::ERR_PROXY_CONNECTION_FAILED`。
   用 `proxy: { server: "direct://" }` **无效**（环境变量仍会覆盖）；
   最终解法 = `launchOptions.args: ["--no-proxy-server"]` + Node 进程 `env -u http_proxy -u https_proxy …`
   + `baseURL` 用 `127.0.0.1` 而非 `localhost`，三者齐上才通。
2. **dev server 会被 Bash 工具的调用结束回收** —— `nohup npx vite … &` / `cmd //c start /B` 都不行，
   启动后 curl 得到 502（当时真的是没进程）。必须用 `run_in_background: true` 启，
   且要**在同一轮里跑完测试**，否则中途 dev server 消失、用例全挂。

另：`rm -rf test-results playwright-report` 在沙箱里撞 `[safe-delete] … ETIMEDOUT`，
需加 `dangerouslyDisableSandbox: true` 才能删。
