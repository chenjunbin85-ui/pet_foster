# 宠物寄养登记与健康档案管理系统 —— 前端原型（React + shadcn/ui）

基于 Vite + React 19 + TypeScript + Tailwind CSS 4 + shadcn/ui（base-nova 风格）构建的高保真可交互原型。

## 运行方式

```bash
pnpm install   # 安装依赖
pnpm dev       # 启动开发服务器（默认 http://localhost:5173）
pnpm build     # 生产构建，产物在 dist/
```

## 演示账号（密码任意）

- 管理员：`admin` —— 可见全部菜单（含系统管理）
- 工作人员：`staff01` —— 系统管理菜单自动隐藏

## 页面与交互（对应完整需求文档第 8 章）

| 页面 | 关键交互 |
| --- | --- |
| 登录页 | 账号密码登录，双角色演示 |
| 系统首页 | 统计卡片、今日待办、在店宠物、快捷入口 |
| 客户信息管理 | 增删改查、搜索、详情弹窗（宠物/历史订单 Tab） |
| 宠物档案管理 | 增删改查、客户下拉、详情弹窗（订单/健康 Tab） |
| 寄养订单管理 | 新建订单（客户→宠物联动、自动算费）、状态流转（待入店→寄养中→已完成/已取消） |
| 健康档案管理 | 入店/观测/离店三类记录、关联订单 |
| 寄养服务记录 | 服务登记、订单带出宠物 |
| 统计分析 | 订单趋势柱状图、品种分布环形图、导出 |
| 系统管理 | 用户账号（角色分配/启停）、操作日志、数据字典（仅管理员） |

## 技术要点

- 组件全部来自 shadcn/ui 官方注册表（`pnpm dlx shadcn@latest add ...`）
- 数据为前端 mock（src/data/mock.ts），对应八张数据表结构，后续可替换为后端 API
- 语义化配色、自适应布局、无 `space-*`、表单使用 FieldGroup/Field 规范
