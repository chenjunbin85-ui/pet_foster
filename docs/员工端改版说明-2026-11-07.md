# 员工端小程序改版说明（去网页壳 + 原生视觉重做）

> 日期：2026-11-07 ｜ 范围：`pet-foster-miniprogram` 员工端 18 页（`staff/home` + `c1–c6 / v1–v5 / g1–g3 / d1–d3`）
> 对应：`docs/员工端小程序产品化差距诊断-2026-11-07.md` 第四节 **P0-1（去网页壳）** + 新增「原生视觉重做」
> 未改动：任何后端接口、SQL、`utils/api.js` 数据契约、页面 `.js` 的提交参数结构

## 一、问题

上一版员工端 18 页由静态 HTML 高保真原型整页搬迁而来，保留了原型为「看起来像手机」而自绘的**假状态栏（9:41 / ▂▄▆ ◔ ▭）、假导航栏、假胶囊（··· ◎）、假 Home 指示条**，页面外层又是 `page{#E9E5DF}` + `width:750rpx;margin:0 auto` 的居中网页容器。

真机/模拟器里，系统状态栏、微信原生胶囊与原型画的手机壳三层叠加，页面上方像浏览器里嵌了一个手机模型——这就是「工作人员小程序界面像网页响应式布局」的直接来源。

## 二、改了什么

### 1. 去网页外壳（P0-1）

| 改动 | 说明 |
|---|---|
| 18 个页面删除 `<view class="topbar">…</view>`（状态栏 + 导航栏 + 胶囊） | 导航交回微信原生导航栏 |
| 18 个 `pages/staff/**/*.json` 由 `navigationStyle: "custom"` 改为 `"default"` | 原生栏直接使用各页已有的 `navigationBarTitleText`；背景 `#F5F1EB`、黑色前景 |
| 删除 `.safe-area` / `.home-indicator` 假 Home 条 | 安全区改用 `env(safe-area-inset-bottom)` |
| 删除 `page` 的灰色底与 `.staff-page{width:750rpx;margin:0 auto}` | 页面铺满视口，不再有「网页里的手机框」 |
| 清理 `cursor` / `user-select` / `resize` / `outline` 等桌面属性 | 仅保留签名 canvas 的 `touch-action:none` |

### 2. 原生视觉规范（重写 `styles/staff.wxss`）

- 设计令牌统一到客户端同一套暖色调：`--bg #F5F1EB`、`--brand #E8743B`、`--ink #2B2724`、`--line #EFE9E1`；卡片 28rpx 圆角 + 极轻投影。
- 字号收敛到 21/23/25/27/30/34/42/52rpx 八级，正文 28rpx，行高 1.55。
- 主 CTA 改为 92rpx 高的胶囊按钮，底部固定操作栏 `position:fixed` + `padding-bottom: env(safe-area-inset-bottom)`，内容区用 `.has-foot` 预留 196rpx。
- 表单：输入框改为浅底无边框（`#F8F4EF`，16rpx 圆角），标签列 168rpx，行内单位与输入框对齐。
- 单选/多选：选项胶囊化，选中态用品牌色描边 + 浅底；勾选行改为圆形勾选。
- 新增组件类：`.hero`（身份/宠物头图）、`.kv`（信息行）、`.meter`（进度条）、`.big-num`、`.workbench-grid`（岗位宫格）、`.foot-note`；旧类名保留，页面改造不必一次性重写。
- 所有规则继续以 `.staff-page` 作用域开头，避免与 `app.wxss` 的客户端 `.card/.btn/.input` 互相覆盖。

### 3. 页面结构与内容

- **员工工作台**：身份卡合并「姓名 / 岗位 / 当班 / 今日统计」，第三个统计由「可用功能」改为**当前班次**；4 个岗位入口改为两列宫格（护理 / 兽医 / 洗护 / 接送），快捷入口保留分组列表；删除开发口径提示「后端每个写接口会再判一次岗位与资质（403 才是真正的边界）」。
- **护理工作台 c1**：当班身份条 + 班次分段 + 巡视进度（大数字 + 进度条 + 待完成次数）+ 任务卡列表；去掉装饰性圆环与写死的「1 次 / 2 次」。
- **巡视打卡 c2**：体温单位贴齐输入框；照片计数改为 `{{photos.p1.items.length}} / 6`。
- **交接签字 c5**：签名人改为 `{{meName}}（{{positionLabel}}）`，寄养日期改为订单日期，去掉「未派房卡 / 自带 2 kg / 待确认」等原型批注。
- **兽医工作台 v1 / 洗护工作台 g1 / 司机工作台 d1**：姓名、头像首字改为登录人；岗位说明改为 `{{positionLabel}}`；司机页「外勤中 / 闽 C·****71 / 今日任务总数 4 趟 / 3 个停靠点」改为真实趟数、停靠点数与首个任务地址。
- **核销成功页 c6 / g3 / d3**：图标 + 标题 + 说明 + 返回按钮，语义类 `.success-title/.success-desc`。
- **只读岗位**：店长进入「护理工作台 / 兽医工作台」时徽标显示「只读」，不再谎称「在岗 / 执业中」。

### 4. 顺带修掉的单选缺陷

原型把同一组单选拆成了独立字段（`spirit / spirit2 / spirit3`、`abtype / abtype2 / …`），于是能同时选中「正常 + 萎靡」，而 `build()` 只读第一个字段（异常上报页选「食欲」实际提交 `其他`）。

现已全部收回到单一字段（`form.spirit`、`form.abtype` 等），并把 `c4.js` 的默认值 `abtype2`、`v3.js` 的默认值 `level2` 同步改为主字段，保证**首项高亮 = 提交值**。
