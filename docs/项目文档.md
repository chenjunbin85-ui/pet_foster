## 一、项目概述

「毛球旅馆」是一套面向宠物寄养门店的全栈演示系统，覆盖三类角色：

- **门店管理员**：经营数据统计、工作人员账号与房型价位维护；可查看订单流水、导出订单。**当前没有客户与宠物档案权限**（`/api/customers`、`/api/pets` 实测 403），也导不出客户/宠物。
- **门店工作人员（前台 / 护理员）**：接待客户、登记客户与宠物档案、办理入离店、录入健康与服务记录；可导出客户/宠物。**没有经营报表权限**（`/api/stats/dashboard` 实测 403），仅首页展示「本月寄养金额」。
- **养宠客户**：微信小程序自助注册登录、选择房型日期与增值服务、下单寄养、查订单与评价。**注册接口当前被安全配置拦截（实测 401）**，实际只能用已有账号登录。

系统由三部分组成：

| 子系统 | 目录 | 技术栈 | 端口 |
| --- | --- | --- | --- |
| 后端服务 | `pet-foster-server-src/pet-foster-server` | Java 20 · Spring Boot 3 · MyBatis-Plus · MySQL 8 · Redis · JWT | 8090 |
| 客户小程序 | `pet-foster-miniprogram` | 原生微信小程序（WXML / WXSS / JS） | — |
| 工作人员/管理员 Web | `pet-foster-ui-src/pet-foster-ui` | React 19 · Vite 8 · TypeScript · Tailwind CSS 4 · shadcn/ui · Recharts | 5173（dev） |

## 二、技术架构

### 2.1 整体分层

```
客户小程序 (WeChat)  ──┐
                       ├──►  Spring Boot 后端 (REST, /api/**)  ──►  MySQL 8 (pet_foster)
工作人员 Web (React) ──┘                                       └─►  Redis (登录失败计数)
```

- 统一返回结构 `Result { code, message, data }`，`code=200` 成功，业务异常 `code=500`。
- 鉴权：JWT（HS256，有效期 24 小时），密码统一 BCrypt 加密。
- 登录失败限流：基于 Redis 计数（5 次 / 5 分钟锁定），见 `LoginAttemptService`。
- 接口文档：SpringDoc OpenAPI，启动后访问 `/swagger-ui.html`。
- CORS：允许 `http://localhost:5173` 等前端来源，可通过环境变量 `CORS_ALLOWED_ORIGINS` 覆盖。

### 2.2 后端模块划分（`com.petfoster`）

| 包 | 职责 |
| --- | --- |
| `controller` | REST 入口，分 web 端（`/api/**`）与小程序端（`/api/mp/**`） |
| `service` | 业务逻辑：登录、客户、宠物、订单、价位、健康记录、服务记录、统计 |
| `mapper` | MyBatis-Plus Mapper，对应每张数据表 |
| `entity` | 与表一一对应的实体 |
| `dto / vo` | 入参校验（Jakarta Validation） / 出参脱敏 |
| `security` | JWT 过滤器、登录用户上下文、登录失败计数 |
| `enums` | 订单状态、支付状态、支付方式、宠物性别 |
| `task` | `OrderExpireTask`：定时关闭超时未支付订单 |
| `common` | 统一 Result、分页、全局异常、业务异常 |

## 三、数据模型（MySQL `pet_foster`）

建表脚本：`pet-foster-server-src/pet-foster-server/sql/schema.sql`；业务扩展表：`src/main/resources/db/v2_business_expansion.sql`；索引优化：`src/main/resources/db/index_optimization.sql`。

### 3.1 账号体系（三表分离）

| 表 | 用途 | 关键字段 |
| --- | --- | --- |
| `sys_admin` | 门店管理员 | `admin_id`、username、password、real_name、status |
| `staff` | 工作人员（前台/护理员/兽医助理） | `staff_id`、username、password、real_name、**position 岗位**、status |
| `customer` | 小程序客户 | `customer_id`、name、phone、address、**username=手机号**、password、status、last_login_time |

### 3.2 业务表

| 表 | 说明 |
| --- | --- |
| `pet` | 宠物档案：所属客户、品种、性别、年龄、体重、疫苗（JSON 编码）、病史 |
| `foster_price` | 寄养房型/价位档位：标准间 60 元、舒适间 80 元、豪华间 120 元（演示数据） |
| `foster_order` | 寄养订单：订单号 `FO+yyyyMMdd+3位序号`、客户、宠物、入离店日期、单日价格快照、总费用、状态、支付信息、支付截止时间（15 分钟）、逻辑删除 |
| `pet_health_record` | 健康记录：入店记录 / 寄养观测 / 离店记录，含体温、精神、食欲、排便、皮肤、异常、处理措施、记录人（staff_id） |
| `foster_service_record` | 服务记录：喂食、遛弯、洗澡等照护动作，含看护人（staff_id） |
| `store` | 寄养门店：名称、地址、电话、营业时间 |
| `coupon` | 客户优惠券：面额、满减门槛、状态、有效期、核销订单 |
| `review` | 订单评价：一个订单一条（UNIQUE）、评分 1–5、文字评价 |
| `care_record` | 小程序端照护动态：按订单+天记录，可附图 |

订单状态机：`待入店 → 寄养中 → 已完成`，异常分支 `已取消`；支付状态：`未支付 → 已支付 / 已退款`。

## 七、核心业务流程（文字描述）

### 7.1 客户注册与登录

新客户在小程序注册页输入手机号（正则 `1[3-9]\d{9}`）、设置 6–32 位密码并二次确认，勾选用户协议后提交。后端校验手机号未占用，BCrypt 加密后写入 `customer` 表（默认昵称「爱宠家长」），随即签发 JWT 返回客户信息，前端保存 token 并自动进入首页。老客户直接用手机号 + 密码登录，连续失败 5 次触发 Redis 计数锁定 5 分钟。

### 7.2 下单寄养

客户在首页选择房型（标准间/舒适间/豪华间）、入住与离店日期，填写特殊照护备注，页面实时按「晚数 × 单日价格」预估金额。提交后进入结算页，核对入住信息、价格明细、联系人、寄养门店，可选择可用优惠券抵扣，确认后调用下单接口生成订单（状态「待入店」，支付状态「未支付」），并写入 15 分钟支付截止时间。客户在支付页完成演示支付后，订单变为「已支付」；超时未支付由后台定时任务 `OrderExpireTask` 自动关闭。

### 7.3 订单履约

订单进入「寄养中」后，工作人员在 Web 端办理入店登记并写入首条健康记录（体温、精神、食欲、皮肤等）。寄养期间护理员可随时新增照护服务记录（喂食、遛弯、洗澡）与每日健康观测；客户在小程序订单详情页实时看到这些照护动态。寄养结束后工作人员办理离店，补离店健康记录，订单变为「已完成」，客户可在小程序对订单进行星级 + 文字评价。任何环节客户或工作人员可取消订单（按规则退款/退订），订单进入「已取消」。

### 7.4 门店后台管理

工作人员登录后在工作台完成日常接待：登记新客户、补录宠物档案、查看待入店订单并办理入离店、登记健康与照护日志。管理员登录后额外看到经营看板（月度营收、订单趋势、品种分布）和系统管理（工作人员账号增删改、房型档位维护）。导出功能支持把客户、宠物、订单导出为 CSV，方便门店线下留存。

## 八、本地启动步骤

### 8.1 准备环境

- JDK 20、Maven（本机可用 IntelliJ 自带 Maven：`C:\Program Files\JetBrains\IntelliJ IDEA 2024.2.3\plugins\maven\lib\maven3\bin\mvn.cmd`）
- MySQL 8（库名 `pet_foster`，账号 root/root，可通过环境变量覆盖）
- Redis（本地 6379，无密码）
- Node.js + pnpm（Web 端）、微信开发者工具（小程序端）

### 8.2 初始化数据库

```bash
mysql -u root -p < pet-foster-server-src/pet-foster-server/sql/schema.sql
mysql -u root -p pet_foster < pet-foster-server-src/pet-foster-server/src/main/resources/db/v2_business_expansion.sql
```

### 8.3 启动后端

```bash
cd pet-foster-server-src/pet-foster-server
mvn spring-boot:run
# 默认端口 8090，接口文档 http://127.0.0.1:8090/swagger-ui.html
```

### 8.4 启动 Web 端

```bash
cd pet-foster-ui-src/pet-foster-ui
pnpm install
pnpm dev      # http://localhost:5173
```

### 8.5 导入小程序

用微信开发者工具导入 `pet-foster-miniprogram` 目录；`utils/api.js` 中 `BASE_URL` 指向 `http://127.0.0.1:8090`，需在开发者工具中关闭「合法域名校验」。
