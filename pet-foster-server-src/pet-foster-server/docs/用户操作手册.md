# 护宠宝 - 宠物寄养登记与健康档案管理系统 用户操作手册

## 一、系统简介

护宠宝是一款面向宠物寄养门店的管理系统，涵盖客户信息管理、宠物档案管理、寄养订单管理、健康档案管理、寄养服务记录、统计分析等功能，帮助门店高效管理寄养业务。

**品牌Slogan**：每一份托付，都用心守护

---

## 二、登录系统

### 2.1 登录页面

1. 打开浏览器，访问系统地址（如 `http://localhost:5173`）
2. 进入登录页面，输入账号和密码
3. 点击「登录」按钮

### 2.2 演示账号

| 角色 | 账号 | 密码 | 说明 |
|------|------|------|------|
| 管理员 | admin | admin123 | 拥有全部功能权限 |
| 工作人员 | staff01 | staff123 | 业务操作权限，无系统管理 |

### 2.3 登录失败处理

- 账号或密码错误：提示"账号或密码错误"，请重新输入
- 账号不存在：提示"用户不存在"
- 空账号或空密码：无法点击登录

## 三、系统首页（门店工作台）

登录成功后进入门店工作台首页，展示门店运营概览：

### 3.1 数据概览卡片

- **寄养中宠物**：当前正在寄养的宠物数量
- **待入店订单**：已创建但尚未确认入店的订单数
- **本月订单**：本月累计寄养订单数
- **本月寄养金额**：本月累计寄养收入

### 3.2 今日待办

- 展示待处理的订单列表
- 点击卡片可直接跳转到订单详情页
- 点击「查看订单」按钮进入寄养订单管理页面

### 3.3 在店宠物状态

- 展示当前寄养中的宠物状态
- 点击卡片可查看宠物详情和健康记录

### 3.4 系统快捷入口

提供常用业务操作的快捷按钮：
- 新建寄养订单
- 新增客户
- 新增宠物档案
- 登记健康记录
- 登记服务记录

点击快捷按钮直接打开对应操作弹窗。

## 四、客户信息管理

### 4.1 查看客户列表

1. 点击左侧导航「客户信息管理」
2. 展示客户列表，包含：客户姓名、电话、地址、备注、创建时间
3. 支持按姓名或电话搜索
4. 列表分页显示，可翻页查看

### 4.2 新增客户

1. 点击「新增客户」按钮
2. 填写客户信息：
   - 客户姓名（必填）
   - 联系电话（必填）
   - 地址
   - 备注
3. 点击「保存」完成新增

### 4.3 编辑客户

1. 在客户列表中找到目标客户
2. 点击「编辑」按钮
3. 修改客户信息
4. 点击「保存」完成修改

### 4.4 删除客户

1. 在客户列表中找到目标客户
2. 点击「删除」按钮
3. 确认删除操作

> 注意：有关联宠物或订单的客户可能无法删除，请先处理关联数据。

---

## 五、宠物档案管理

### 5.1 查看宠物列表

1. 点击左侧导航「宠物档案管理」
2. 展示宠物档案列表，包含：宠物名、品种、性别、年龄、体重、所属客户
3. 支持按宠物名或品种搜索

### 5.2 新增宠物档案

1. 点击「新增宠物」按钮
2. 填写宠物信息：
   - 宠物名称（必填）
   - 所属客户（必填，下拉选择）
   - 品种（必填）
   - 性别
   - 年龄
   - 体重
   - 毛色
   - 疫苗情况
   - 病史/过敏史
3. 点击「保存」完成新增

### 5.3 查看宠物详情

1. 在宠物列表中点击宠物名称
2. 查看宠物完整档案信息
3. 可查看该宠物的寄养历史和健康记录

---

## 六、寄养订单管理

### 6.1 查看订单列表

1. 点击左侧导航「寄养订单管理」
2. 展示订单列表，包含：订单号、客户、宠物、寄养时间、状态、总费用
3. 支持按状态筛选（全部/待入店/寄养中/已完成/已取消）
4. 支持按订单号搜索

### 6.2 订单状态说明

| 状态 | 说明 | 可执行操作 |
|------|------|------------|
| 待入店 | 订单已创建，宠物尚未到店 | 确认入店、修改、取消 |
| 寄养中 | 宠物正在寄养 | 确认离店、取消（管理员） |
| 已完成 | 宠物已离店，订单结束 | 查看详情 |
| 已取消 | 订单已取消 | 查看详情 |

### 6.3 新建寄养订单

1. 点击「新建订单」按钮
2. 填写订单信息：
   - 客户（必填，下拉选择）
   - 宠物（必填，下拉选择，仅显示该客户的宠物）
   - 开始日期（必填）
   - 结束日期（必填，不能早于开始日期）
   - 每日单价（必填）
   - 备注
3. 系统自动计算总费用 = 每日单价 × 寄养天数
4. 点击「保存」完成创建

### 6.4 确认入店

1. 在订单列表中找到「待入店」状态的订单
2. 点击「确认入店」按钮
3. 订单状态变更为「寄养中」

### 6.5 确认离店

1. 在订单列表中找到「寄养中」状态的订单
2. 点击「确认离店」按钮
3. 订单状态变更为「已完成」

### 6.6 取消订单

> 仅管理员可取消订单

1. 在订单列表中找到目标订单
2. 点击「取消订单」按钮
3. 确认取消操作
4. 订单状态变更为「已取消」

## 七、健康档案管理

### 7.1 查看健康记录

1. 点击左侧导航「健康档案管理」
2. 展示健康记录列表，包含：宠物、关联订单、记录时间、记录内容
3. 支持按宠物名搜索

### 7.2 登记健康记录

1. 点击「登记健康记录」按钮
2. 填写记录信息：
   - 宠物（必填，下拉选择）
   - 关联订单（可选，下拉选择该宠物的寄养订单）
   - 记录时间（必填）
   - 健康状况描述（必填）
   - 处理措施
3. 点击「保存」完成登记

### 7.3 健康记录用途

- 记录宠物寄养期间的健康状况
- 异常情况及时登记，便于追溯
- 离店时可作为健康交接依据

## 八、寄养服务记录

### 8.1 查看服务记录

1. 点击左侧导航「寄养服务记录」
2. 展示服务记录列表，包含：订单、宠物、服务时间、服务项目、描述
3. 支持按服务项目筛选

### 8.2 登记服务记录

1. 点击「登记服务」按钮
2. 填写服务信息：
   - 关联订单（必填，下拉选择）
   - 宠物（自动填充）
   - 服务时间（必填）
   - 服务项目（必填，如：喂食、遛狗、洗澡、美容等）
   - 服务描述
3. 点击「保存」完成登记

## 九、统计分析

### 9.1 数据概览

1. 点击左侧导航「统计分析」
2. 展示多维度统计图表：

- 默认显示最早订单日期到今天的数据

### 9.3 数据导出

- 统计数据支持导出为Excel
- 客户列表、宠物列表、订单列表均支持导出

## 十一、常见问题

### Q1：忘记密码怎么办？
A：请联系管理员重置密码。管理员可在系统管理-用户管理中重置用户密码。

### Q2：新建订单时找不到客户或宠物？
A：请先在「客户信息管理」中添加客户，再在「宠物档案管理」中为该客户添加宠物。

### Q3：订单创建后能修改吗？
A：「待入店」和「寄养中」状态的订单可以修改，「已完成」和「已取消」的订单不能修改。

### Q4：工作人员能取消订单吗？
A：不能。取消订单仅限管理员操作，工作人员无此权限。

### Q5：数据会丢失吗？
A：数据存储在MySQL数据库中，建议定期备份数据库。

### Q6：支持多门店吗？
A：当前版本为单门店系统，多门店支持可在后续版本扩展。
