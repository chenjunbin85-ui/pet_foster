## 三、数据库初始化

### 3.1 创建数据库

```sql
CREATE DATABASE pet_foster DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 3.2 执行初始化脚本

数据库脚本位于：`pet-foster-server/src/main/resources/db/`

按顺序执行：

1. `schema.sql` - 建表脚本（8张业务表）
2. `data.sql` - 初始数据（管理员账号、字典数据等）
3. `index_optimization.sql` - 索引优化脚本（28个索引）

```bash
# 命令行执行示例
mysql -u root -p pet_foster < schema.sql
mysql -u root -p pet_foster < data.sql
mysql -u root -p pet_foster < index_optimization.sql
```

### 3.3 默认账号

| 角色 | 账号 | 密码 | 权限 |
|------|------|------|------|
| 管理员 | admin | admin123 | 全部功能 |
| 工作人员 | staff01 | staff123 | 业务操作（无系统管理） |

### 3.4 数据库表结构

| 表名 | 说明 | 主要字段 |
|------|------|----------|
| sys_user | 系统用户 | user_id, username, password, role, status |
| customer | 客户信息 | customer_id, name, phone, address |
| pet | 宠物档案 | pet_id, customer_id, name, breed, gender, age |
| foster_order | 寄养订单 | order_id, order_no, customer_id, pet_id, status, total_fee |
| pet_health_record | 健康记录 | record_id, pet_id, order_id, record_time, content |
| foster_service_record | 服务记录 | record_id, order_id, pet_id, service_time, item |
| sys_dict | 数据字典 | dict_id, type_code, dict_label, dict_value |

## 四、后端部署

### 4.1 修改配置文件

编辑 `src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/pet_foster?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: root
    password: your_password  # 修改为你的MySQL密码
    driver-class-name: com.mysql.cj.jdbc.Driver

server:
  port: 8090

jwt:
  secret: your-jwt-secret-key  # 生产环境请修改为复杂密钥
  expiration: 86400000  # 24小时
```

### 4.2 编译打包

```bash
cd pet-foster-server-src/pet-foster-server

# 设置JAVA_HOME（Windows）
set JAVA_HOME=C:\Java\jdk-21

# 编译
mvn clean compile

# 打包（跳过测试）
mvn package -DskipTests
```

打包成功后，jar包位于：`target/pet-foster-server-1.0.0.jar`

### 4.3 启动服务

```bash
# 方式一：Maven启动（开发环境）
mvn spring-boot:run

# 方式二：Jar包启动（生产环境）
java -jar target/pet-foster-server-1.0.0.jar

# 方式三：后台运行（Linux）
nohup java -jar target/pet-foster-server-1.0.0.jar > app.log 2>&1 &
```

### 4.4 验证启动

访问：`http://localhost:8090/swagger-ui.html`

能看到Swagger接口文档页面说明启动成功。

## 五、前端部署

### 5.1 安装依赖

```bash
cd pet-foster-ui-src/pet-foster-ui

# 使用npm
npm install

# 或使用pnpm（推荐）
pnpm install
```

### 5.2 修改API地址

编辑 `src/api/client.ts`：

```typescript
const BASE_URL = "http://your-server-ip:8090"  // 修改为后端实际地址
```

### 5.3 开发模式启动

```bash
npm run dev
```

访问：`http://localhost:5173`

### 5.4 生产构建

```bash
npm run build
```

构建产物位于：`dist/` 目录

### 5.5 Nginx部署（生产环境）

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态资源
    location / {
        root /var/www/pet-foster/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端API反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8090/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 六、Docker部署（可选）

### 6.1 后端Dockerfile

```dockerfile
FROM eclipse-temurin:21-jre
WORKDIR /app
COPY target/pet-foster-server-1.0.0.jar app.jar
EXPOSE 8090
```

```dockerfile

WORKDIR /app

COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
```

### 6.3 docker-compose.yml

```yaml
version: '3.8'
services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: pet_foster

      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql

    build: ./pet-foster-server
    ports:
      - "8090:8090"
    depends_on:
      - mysql

  frontend:
    build: ./pet-foster-ui
    ports:
      - "80:80"
    depends_on:
      - backend

  mysql_data:
```

## 七、常见问题

### Q1：后端启动失败，提示数据库连接失败
A：检查MySQL是否启动，application.yml中的数据库地址、账号、密码是否正确。

### Q2：前端页面空白，控制台报CORS错误
A：后端已配置CORS允许所有来源，检查前端BASE_URL是否正确，后端是否正常启动。

### Q3：登录提示"账号或密码错误"
A：确认data.sql已执行，默认账号admin/admin123，密码使用BCrypt加密。

### Q4：Swagger页面404
A：确认访问地址为 `http://localhost:8090/swagger-ui.html`，SpringDoc依赖已引入。

### Q5：修改前端代码后页面不更新
A：Vite开发模式支持热更新，保存后自动刷新；生产环境需重新build。

## 八、运维建议

1. **定期备份数据库**：`mysqldump -u root -p pet_foster > backup.sql`
2. **日志管理**：后端日志输出到控制台，生产环境建议配置文件日志
3. **性能监控**：可接入Spring Boot Actuator + Prometheus + Grafana
4. **安全加固**：生产环境修改默认密码、JWT密钥，配置HTTPS
5. **数据迁移**：升级版本前先备份数据库，执行增量SQL脚本
