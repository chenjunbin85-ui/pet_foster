## EXPLAIN 分析结果

### 优化前
- 客户列表：ALL（全表扫描）+ Using filesort
- 订单列表：ALL（全表扫描）+ Using filesort
- 宠物列表：ALL（全表扫描）+ Using filesort
- 健康记录：ALL（全表扫描）+ Using filesort

### 优化后
| 查询 | type | key | Extra | 结论 |
|------|------|-----|-------|------|
| 订单按状态筛选 | ref | idx_order_status_create | Backward index scan | 最优，索引覆盖排序 |
| 宠物按客户筛选 | ref | idx_pet_customer_create | Backward index scan | 最优，索引覆盖排序 |
| 健康记录按宠物 | ref | idx_health_pet_time | Backward index scan | 最优，索引覆盖排序 |
| 客户手机号模糊搜索 | ALL | NULL | Using where; Using filesort | 前导通配符无法用索引，数据量小不影响 |

## 已知限制
- `phone LIKE '%xxx%'` 前导通配符查询无法使用B+树索引，如需优化可考虑全文索引或Elasticsearch
- 当前数据量较小（<20条），索引性能提升不明显，但数据量增长后效果显著
