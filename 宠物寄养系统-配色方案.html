宠物寄养管理系统 · 配色方案

Design Tokens / Color System · v1.0 · 2026-10-09

一套以暖橙（色相 45°）为主线的双模式配色系统。所有色彩以 OKLCH 色彩空间定义，天然保证同色相下的明度一致性；亮色与暗色为两套独立推演的结果，而非简单反色。

色彩空间OKLCH
品牌主色#B64E10
主题模式亮色 / 暗色
基础圆角0.625rem
字体Geist Variable
定义位置src/index.css

1 · 品牌主色

主色是焦橙色，色相固定在 45°，在 OKLCH 中表现为 oklch(0.55 0.15 45)。整个系统的彩色变化都围绕这条色相线展开——secondary、muted、accent、border、ring、sidebar-* 的色相全部是 45，只调整明度与彩度。这样界面不会出现"橙里带粉""橙里带绿"的色彩污染。

--primary#B64E10
--ring#C65D26
--chart-1#D95800
--accent-foreground#631600

暗色模式下主色提亮为 oklch(0.85 0.12 45) = #FFB48B，同时彩度从 0.15 降到 0.12，避免高亮色在深底上刺眼。

5 · 对比度检查（WCAG 2.1）

正文与交互色按 AA 标准（普通文字 ≥ 4.5:1，图形元素 ≥ 3:1）核算，结果为浏览器实测色值的精确计算值。

发现一处问题（亮色 · 图表黄）
--chart-2 在亮色下是 oklch(0.8 0.14 85) = #E7B643，对白底对比度仅 1.88 : 1，低于图形元素建议的 3 : 1 —— 在白色卡片上做折线时几乎看不清。暗色下同一色值对比度 10.53，没有问题。

建议改法：只降明度，不动色相与彩度，同时与 chart-1/3/4 的明度对齐（它们都是 0.62）： 
--chart-2: oklch(0.62 0.14 85);   /* #E7B643 → #AC7D00 , 对比度 1.88 → 3.69 */

7 · 使用规范

业务代码不直接写色值，一律通过语义变量使用；Tailwind 已把变量映射为工具类。

/* 只写语义类名 */
<button class="bg-primary text-primary-foreground">保 存</button>
<p class="text-muted-foreground">说明文字</p>
<div class="border border-border bg-card rounded-lg">卡片</div>

/* 需要自定义时引用变量，不要硬编码 */
style="color: var(--chart-1)"

/* ❌ 禁止 */
style="color: #B64E10"
Tailwind 类对应变量使用场景
bg-primary / text-primary--primary主操作按钮、激活态图标
text-muted-foreground--muted-foreground所有次要说明文字
bg-accent--accent导航悬停/选中、菜单聚焦
text-destructive--destructive删除、校验错误
border-border--border卡片、表格、分隔线

8 · 维护说明

主题集中在 src/index.css：:root 为亮色，.dark 为暗色，两处必须成对修改。

修改流程：

1. 改动前先算对比度（正文 ≥ 4.5:1，图形 ≥ 3:1）
2. 只调明度/彩度，保持色相 45 不漂移
3. :root 与 .dark 同步改，避免某一模式漏改
4. 改完在设计稿里过一遍暗色模式
